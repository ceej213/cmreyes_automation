Invoice & document intelligence

The AI reads it. Ordinary code does the maths.

Language models are excellent at reading a messy scan and the wrong thing to trust with money — so the split is strict: Claude transcribes what is printed, and deterministic code checks every sum in integer cents.

In

Drop an invoicePDF, PNG, JPEG, WebP or GIF — from the inbox or the upload page.
max 3 MB

Extract

Required fields presentNothing silently missing
Line item mathsqty × unit price, per row
Sums reconcileLines → subtotal → total, in cents
Duplicate defenceKeyed on vendor + invoice number — a re-scan updates the record, it never adds one

Out

Ledger recordClean invoices are written straight to Airtable. Anything that fails a check is held for review with the failure named — a finding, not a quiet fix.
